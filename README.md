# Gestion-heure

Application web progressive (PWA) en français pour le suivi des heures et montants à facturer.

## Mise en ligne sur GitHub Pages
1. Décompressez l'archive.
2. Dans le dépôt GitHub `Gestion-heure`, choisissez **Add file > Upload files**.
3. Importez les fichiers et dossiers contenus dans l'archive (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png). Il faut que `index.html` soit à la racine du dépôt.
4. Validez avec **Commit changes**.
5. Dans **Settings > Pages**, choisissez **Deploy from a branch**, branche `main`, dossier `/(root)`, puis **Save**.
6. Attendez la publication et ouvrez le lien indiqué par GitHub Pages.
7. Sur iPhone, ouvrez le lien dans Safari > Partager > **Sur l’écran d’accueil**.

## Données
Les données sont stockées localement dans le navigateur. Utilisez l'onglet Sauvegarde pour exporter/importer un fichier JSON. Conservez des sauvegardes régulières.

## À savoir
La provision MSA est une estimation configurable, pas un calcul officiel. Vérifiez le taux de TVA applicable à chaque prestation. Les fichiers de l'application peuvent être publics si le dépôt est public ; n'y ajoutez aucune donnée client.
